Privacy Policy

Last updated: June 24, 2026

This Privacy Policy describes how the QBO Read-Only Audit Tool ("the Application") handles information. The Application is a private, single-user tool operated by Jason Nickel for the sole purpose of reviewing and auditing the operator's own QuickBooks Online company data. It is not offered to the public.

1. Information We Access

With the operator's explicit authorization through Intuit's OAuth 2.0 flow, the Application reads accounting data from a single QuickBooks Online company, including transactions, accounts, lists, and financial reports. Access is strictly read-only; the Application does not create, modify, or delete any data in QuickBooks Online.

2. How Information Is Used

Data accessed through the QuickBooks Online API is used only to display and analyze the operator's own financial records for personal bookkeeping review and audit. The data is not used for advertising, profiling, or any purpose beyond the operator's own review.

3. Information Sharing

The Application does not sell, rent, trade, or otherwise disclose accessed data to any third party. No data is transmitted to any server operated by a third party as part of the Application's normal operation.

4. Data Storage and Security

The Application runs locally on hardware controlled by the operator. OAuth access and refresh tokens are stored in the operator's private secrets manager and used only to authenticate to Intuit's API. No accounting data is persisted to any public or third-party location by the Application.

5. Data Retention and Revocation

The operator may revoke the Application's access at any time from QuickBooks Online under Settings → Apps → Connected Apps, or via the Intuit account security settings. Upon revocation, the stored tokens become invalid and no further data can be accessed.

6. Contact

Questions about this Privacy Policy may be directed to jason@jasonnickel.com.
